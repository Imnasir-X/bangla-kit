# Security policy

`bangla-kit` has no runtime dependencies and makes no network calls. `bangla-kit-mcp` runs locally over stdio and only formats text.

To report a vulnerability, open a private advisory at https://github.com/Imnasir-X/bangla-kit/security/advisories/new. You will get a reply within 48 hours. Please do not open a public issue for security reports.

Supported versions: the latest minor release.
